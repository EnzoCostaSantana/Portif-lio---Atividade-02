Seção 2 — Ranking de tecnologias

  1. JavaScript: Essencial para lógica no lado do cliente.

  2. HTML5: A estrutura base de toda a web.

  3. CSS3: Responsável pelo design e layout.

  4. Node.js: Permite execução do JS no servidor.

  5. SQL: Linguagem padrão para bancos de dados.

Seção 3 — Glossário de termos técnicos

API
Interface de Programação de Aplicações.
Conjunto de rotinas e padrões para acesso a um software.
Navegador
Browser
Software utilizado para acessar a internet.
URL
Endereço web.
DNS
Sistema que converte nomes de domínio em endereços IP.
HTTP
Protocolo de transferência de hipertexto.
DOM
Modelo de Objeto de Documento.
